# GameNotes

The design notes for **Severance**, an FFXIV-style dungeon-crawler MMO I'm planning. This is an [Obsidian](https://obsidian.md) vault where I plan the classes, lore, dungeons and combat before building them.

The playable text prototype is in [severance-text](https://github.com/NoisyBoy2905/severance-text).

## The idea

Dungeons have been appearing across the world for two thousand years, growing bigger and more dangerous. Three pillars (**Science**, **Magic** and **Religion**) each have their own theory of why. None of them agree, but none of them can survive the dungeons alone. Players mix classes from all three pillars in parties of four.

4. 3D single-player in Unity
5. 3D multiplayer
